# Acrely

**Acrely** is a self-hosted, Docker-based real estate operations platform for **Kresta Infra & Developers**. It replaces Excel-based tracking of land acquisition, plot sales, customer payments, expenses, and documents with a single web app, usable from desktop and mobile.

First project onboarded: **Meadow Breeze** (126 plots / ~63 acres, Telangana).

---

## Phase 1 — Foundation (this branch)

Phase 1 ships the infrastructure and shell. No land, plot, payment, or document screens yet — those land in later phases.

**What's included**

- Docker Compose stack: Postgres 15, GoTrue (auth), PostgREST, Realtime, Storage, imgproxy, pg-meta, Supabase Studio, Kong gateway, and the Acrely Next.js 15 web app.
- Inbucket email catcher on `:9000` so email-OTP login works out of the box with no external SMTP.
- Email OTP login via Supabase Auth.
- App shell: sidebar, project switcher, topbar with user menu, mobile bottom nav.
- Projects CRUD (create, edit, list).
- Foundation migrations: `projects`, `accounts`, `expense_categories` (seeded), `rate_card`, `receipt_sequences`, `activity_log`, `user_profiles` (role-ready), RLS policies.
- Collision-safe receipt-number function (`public.next_receipt_number`).
- `formatINR` + `formatINRCompact` + `formatDate` utilities (Indian grouping).
- `/api/health` for Docker healthchecks.
- Noto Sans Telugu loaded globally so Telugu names and plot numbers render correctly.
- Setup scripts: `init.sh` (generates JWT secret + anon/service keys), `dev.sh`, `start.sh`.

## Prerequisites

- **Docker Desktop** (Windows / macOS) or **Docker Engine 24+** with Compose v2 (Linux).
- `openssl` on the host (used by `init.sh` to generate secrets).
- For dev mode only: **Node.js 20+** and **npm 10+**.

## Quick start

```bash
git clone <this-repo> acrely
cd acrely
cp .env.example .env
./scripts/init.sh        # generates JWT_SECRET, ANON_KEY, SERVICE_ROLE_KEY
./scripts/start.sh       # builds + starts everything
```

Open:

- App: <http://localhost:3000>
- Supabase Studio: <http://localhost:3001>
- Email catcher (OTP inbox): <http://localhost:9000>
- Supabase API (Kong): <http://localhost:8000>

---

## First login

1. Open <http://localhost:3000>. You'll be redirected to `/login`.
2. Enter any email (e.g. `you@kresta.test` — Supabase creates the auth user automatically). Hit **Send code**.
3. Open <http://localhost:9000> (Inbucket) and click the latest email to read the 6-digit OTP.
4. Enter the code and you're in.
5. Create your first project ("Meadow Breeze", slug `meadow-breeze`).

Once you're comfortable, set `DISABLE_SIGNUP=true` in `.env` so no one else can create an account.

## Two ways to run

### Production mode (everything in Docker)

```bash
./scripts/start.sh
```

Builds the Next.js image and brings up the whole stack. Best for actual use.

### Dev mode (hot reload on host)

```bash
./scripts/dev.sh        # Supabase stack only
npm install
npm run dev             # Next.js on host, port 3000
```

## Environment variables

See `.env.example` for the full list. Highlights:

| Variable | Purpose |
| --- | --- |
| `POSTGRES_PASSWORD` | Auto-generated by `init.sh`. |
| `JWT_SECRET` | Signs Supabase JWTs. Auto-generated. |
| `ANON_KEY` / `SERVICE_ROLE_KEY` | Derived JWTs. Auto-generated. |
| `APP_NAME` / `COMPANY_NAME` | Branding displayed in the UI. |
| `SITE_URL` | Public URL of the Next.js app (used in auth callbacks). |
| `API_EXTERNAL_URL` | Public URL of the Supabase API (Kong). |
| `DISABLE_SIGNUP` | Set `true` after your first account to lock down auth. |
| `SMTP_*` | For real email in production. Dev uses Inbucket. |
| `CLOUDFLARE_TUNNEL_TOKEN` | Optional, for remote access via Cloudflare Tunnel (Phase 6). |

`.env` is git-ignored. Never commit it.

## Where data lives

Two Docker named volumes hold all your legal records. Back these up daily.

| Volume | Contents |
| --- | --- |
| `acrely_db_data` | Postgres database — pattadars, parcels, plots, customers, bookings, payments, activity log. |
| `acrely_storage_data` | Uploaded documents — agreements, IDs, receipt PDFs. |

On Linux: `docker volume inspect acrely_db_data` shows the host path (usually under `/var/lib/docker/volumes/`).

On Windows (Docker Desktop): volumes are inside the WSL2 VM; back up via the scripts below rather than poking at the filesystem.

## Backup & restore (Phase 6 — preview)

Phase 6 adds `scripts/backup.sh`, `scripts/restore.sh`, and `scripts/backup-to-cloud.sh`. Basic manual approach in the meantime:

```bash
# DB dump
docker compose exec -T db pg_dump -U postgres postgres | gzip > db_backup.sql.gz

# Storage volume
docker run --rm -v acrely_storage_data:/data -v "$(pwd)":/backup alpine \
  tar czf /backup/storage_backup.tar.gz -C /data .
```

## Mobile access

Three options, in order of preference:

### 1. Tailscale (recommended)

1. Install Tailscale on your PC + phone, sign in with the same account.
2. Run Acrely on the PC with `./scripts/start.sh`.
3. On the phone, open `http://<pc-tailscale-name>:3000`.

Zero port forwarding, encrypted end to end, free for personal use.

### 2. Cloudflare Tunnel

Set `CLOUDFLARE_TUNNEL_TOKEN` in `.env`, then:

```bash
docker compose --profile tunnel up -d
```

You get a public HTTPS URL provisioned via Cloudflare. Phase 6 documents this in detail.

### 3. Router port-forward + DDNS

Works, but exposes Acrely to the internet on your home IP. Discouraged unless you understand the risks. Put a reverse proxy with HTTPS (Caddy / Nginx / Traefik) in front.

## Reset everything

> ⚠ **Destructive.** Deletes ALL data in both volumes. Back up first.

```bash
docker compose down -v
```

Then `./scripts/init.sh && ./scripts/start.sh` to start fresh.

## Troubleshooting

### Port 3000 / 8000 / 5432 / 3001 already in use

Change the host-side port in `.env`:

```
WEB_PORT=3010
KONG_HTTP_PORT=8010
POSTGRES_PORT=5433
STUDIO_PORT=3011
```

### Login fails silently

Check the Inbucket inbox at <http://localhost:9000>. If no email arrives, `docker compose logs auth` will show the GoTrue reason. Most common cause: `GOTRUE_SMTP_*` env vars misconfigured for a real SMTP server.

### Telugu script renders as boxes

The app loads Noto Sans Telugu from Google Fonts. If you're offline or have CSP blocking it, host the font yourself and swap the `@import` in `app/globals.css`.

### Windows volume permission issues

If Docker Desktop complains about volume mounts on Windows, enable WSL2 backend in Docker Desktop settings.

### Health check failing

```bash
docker compose ps            # which container is unhealthy?
docker compose logs <name>   # why?
```
